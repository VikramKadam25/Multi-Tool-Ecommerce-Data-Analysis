## End-to-End E-Commerce Analytics Dashboard Project

An end-to-end e-commerce data analytics project built using Excel, SQL, Power BI, and Tableau analyzing the E-Commerce dataset. 

Rather than simply replicating the same layout across tools, this project leverages the unique strengths of each platform—calculating core overarching metrics while exploring tailored KPIs, custom page navigation, interactive help guides, and visual layouts in each software.


## Multi-Tool Architecture & Tech Stack


Microsoft Excel:- Data Preparation & Executive Spreadsheet Dashboard Custom Pivot Tables, Slicers, Weekday/Weekend Order Split, Dedicated Help Tab 
Power BI:- Interactive Enterprise Reporting & Demographics , Custom Measures (DAX), High-Contrast Executive Layout, Action Buttons & Tooltips 
Tableau:-  Visual Analytics , Customer State Distribution (Treemap) , Freight Cost Analysis
SQL :- Data Extraction & Relational Querying ,Complex Aggregations, Table Joins, Data Cleansing, and Key E-Commerce Queries

## Integrated Page Navigation, Help Pages & User Support

To ensure seamless navigation for non-technical stakeholders, all dashboards feature full User interface And User Experience usability enhancements:

* Interactive Page Navigation: Clear tab switching and button controls (Dashboard -- Help / User Guide) across Excel, Power BI, and Tableau.
* Embedded Help & Guidance Pages: Dedicated help sheets and info icons ('?' / 'i') providing clear documentation on slicers, filters, and chart definitions.
* Direct Support Integration: Embedded support panels with actionable contact links (analytics-support@company.com') built directly into the dashboard canvasses for instant technical escalation.


#### 4. SQL Queries & Relational Data Analytics
* Focus: Database querying, KPI aggregation, and relational table analysis.
* Unique Queries / Calculations:
  * Core Metrics: Extracted total volume for orders, customers, sellers, product categories, and average freight costs.
  * Order Timing & Demographics: Aggregated order density across weekdays vs. weekends and mapped distinct customer city counts.
  * Payment & Seller Performance: Categorized payments by type and calculated top 10 states by customer concentration and average seller freight charges.



## Core Business Insights & Findings
 1. Credit Card Preference: Over 77000 of transactions are completed via Credit Card, indicating a strong preference for installment-based payments.
 2. Weekday Purchase Dominance: 77% of orders are placed during weekdays, suggesting targeted marketing and promotional campaigns should peak Monday through Friday.
 3. Geographic Concentration: São Paulo (SP) accounts for the overwhelming majority of both total sales volume and active customers, presenting opportunities for localized distribution hubs to lower average freight costs.
5. Mid-Year Purchasing Surge: Order volume consistently peaks during Q2/Q3 (29K orders) before dropping in Q4 (18K orders), suggesting seasonal purchasing behaviors that require targeted Q4 promotional campaigns.
6. Top-Heavy Product Demand: Revenue is heavily concentrated in essential lifestyle categories—Beauty & Health, Bed/Bath/Table, and Sports/Leisure—which consistently drive the majority of platform traffic and sales volume.
